📖 Manga Indo Auto Translate

Terjemahkan dialog manga yang sedang terlihat di layar menjadi bahasa Indonesia.

Masukkan API key, simpan, lalu klik Mulai saat halaman manga terbuka.

Belum punya API key? Buat API key di Google AI Studio.

Catatan: Google AI Pro tidak otomatis mencakup kuota Gemini API. API memiliki batas dan ketentuan penggunaan tersendiri. API key disimpan di profil Chrome lokal dan dikirim hanya ke server Gemini saat menerjemahkan. Jangan bagikan key atau folder extension ini.
